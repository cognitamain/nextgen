## Adding a new Blog Post
1. Click Add New Blog Post
2. Give you post a title
3. Add Post description under the content editor section.
4. Add a the primary image in the Featured Image section
5. Add Blog Catgeories.
6. Save your post as a draft or publish button

## Differnce between Posts and Custom post type Blog

1. Posts are Built-in content type in WordPress.
2. Primarily used for blog posts, news, and other time-sensitive content.
3. Organized using categories and tags (taxonomy).
4. Appears in the main blog feed.
5. Can be displayed in reverse chronological order.
6. Supports features like author, comments, and RSS feeds by default.

2. Custom Post Type Blog
1. A user-defined content type that extends the default post functionality.
2. Useful for creating structured content like portfolios, testimonials, products, events, FAQs, etc.
3. Can have custom taxonomies (e.g., a "Genre" taxonomy for a "Movies" CPT).
4. Does not appear in the default blog feed unless explicitly added.
5. Custom templates and metaboxes can be assigned for different layouts.

## Adding a Sidebar
1. Click Appearance > Widgets.
2. Drag NextGen Global Blog to the sidebar.
3. Add a Sidebar Title.
4. Specify the Number of Posts to Show.
5. Select Order By and Order options.
6. Check the checkbox to Show Featured Image, or leave it unchecked if you don’t want to display it.
7. Check the checkbox to Display Categories.
8. Check the checkbox to Display Date.
9. Click the Save button.
