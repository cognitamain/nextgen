## Description

The 3 Columns Thumbnails element is used to create a layout that displays an image, title, and button across three columns.
You can configure several options from the admin side to enhance how the element appears on the frontend.

## Using the 3 Collumn Thumbnails Component

1. Open the WPBakery Frontend Editor on the page you want to edit.
2. Click the + icon in the top menu to open the WPBakery component menu.
3. Navigate to the section Cognita Elements.
4. Select the 3 Column Thumbnails option.
5. The settings box will appear.
6. Add an engaging image and title.
7. Add the buttons and corresponding URL links.
8. Click Save. The component will be added at the end of the page.
9. To reposition it, drag the component using the handle on the left side of the row.


For more details on managing rows, refer to this article:
[Creating columns](/nextgen/SettingUpAGrid/)

## Pro Tip
> To create additional thumbnails, simply copy the repeater within the element and update the content as needed.
